VERIFICATION

Verification is intended to assist the Chocolatey moderators and community in
verifying that this package's contents are trustworthy.

This package is maintained by the author of MultiSnip. It embeds no binaries:
chocolateyinstall.ps1 downloads the MSI from the official GitHub release of the
same project, which is also the only place MultiSnip is published:

  https://github.com/BjWe/MultiSnip/releases

The installers are built from that repository by the release workflow in
.github/workflows/release.yml and uploaded by it, so the download URL and the
source tree are the same origin.

To verify the checksums embedded in chocolateyinstall.ps1, download the two MSI
files for the matching version and compare:

  Get-FileHash MultiSnip-<version>-x64.msi -Algorithm SHA256
  Get-FileHash MultiSnip-<version>-x86.msi -Algorithm SHA256

GitHub also reports the digest of every release asset, which can be compared
without downloading anything:

  curl -s https://api.github.com/repos/BjWe/MultiSnip/releases/tags/v<version>
